# سامانه رزرو آنلاین نوبت

این پروژه یک سامانه ساده و آموزشی برای رزرو آنلاین نوبت است. بک‌اند با Node.js، Express، SQLite، JWT و bcrypt ساخته شده و فرانت‌اند با HTML، CSS و JavaScript ساده پیاده‌سازی شده است.

## امکانات

- ثبت‌نام کاربر
- ورود کاربر
- مشاهده خدمات قابل رزرو
- رزرو نوبت
- مشاهده نوبت‌های خود کاربر
- لغو نوبت توسط کاربر
- پنل ادمین برای مشاهده همه نوبت‌ها
- تایید یا لغو نوبت‌ها توسط ادمین
- ساخت خودکار دیتابیس و داده‌های اولیه

## پیش‌نیازها

برای اجرای پروژه به موارد زیر نیاز دارید:

- Node.js
- npm

## نصب و اجرای بک‌اند

ابتدا وارد پوشه بک‌اند شوید:

```bash
cd backend
```

پکیج‌ها را نصب کنید:

```bash
npm install
```

سرور را اجرا کنید:

```bash
npm start
```

برای حالت توسعه می‌توانید از nodemon استفاده کنید:

```bash
npm run dev
```

بعد از اجرا، بک‌اند روی آدرس زیر در دسترس است:

```text
http://localhost:3000
```

## فایل محیطی `.env`

فایل `backend/.env` شامل تنظیمات محیطی پروژه است:

```env
PORT=3000
JWT_SECRET=replace_this_with_a_secure_secret
```

توضیح متغیرها:

- `PORT`: پورتی که سرور روی آن اجرا می‌شود. مقدار پیش‌فرض `3000` است.
- `JWT_SECRET`: کلید محرمانه برای ساخت و بررسی توکن‌های JWT.

در پروژه یک فایل نمونه با نام `.env.example` هم وجود دارد.

## دیتابیس

دیتابیس SQLite به صورت خودکار هنگام اجرای بک‌اند ساخته می‌شود:

```text
backend/database.sqlite
```

اگر جدول‌ها وجود نداشته باشند، برنامه آن‌ها را می‌سازد:

- `users`
- `services`
- `appointments`

همچنین اگر جدول خدمات خالی باشد، این خدمات اولیه اضافه می‌شوند:

- General Consultation
- Nutrition Consultation
- Dentistry

## اطلاعات ورود ادمین

یک کاربر ادمین به صورت خودکار ساخته می‌شود، البته فقط اگر از قبل وجود نداشته باشد:

```text
Email: admin@example.com
Password: 123456
Role: admin
```

رمز عبور ادمین به صورت هش‌شده با bcrypt ذخیره می‌شود و به شکل متن ساده داخل دیتابیس قرار نمی‌گیرد.

## اجرای فرانت‌اند

ابتدا مطمئن شوید بک‌اند اجرا شده است. سپس فایل زیر را در مرورگر باز کنید:

```text
frontend/index.html
```

فرانت‌اند درخواست‌های خود را به این آدرس ارسال می‌کند:

```text
http://localhost:3000/api
```

توکن JWT بعد از ورود یا ثبت‌نام در `localStorage` ذخیره می‌شود.

## مسیرهای API

### احراز هویت

```http
POST /api/register
POST /api/login
```

### خدمات

```http
GET /api/services
```

این مسیر عمومی است و نیازی به توکن ندارد.

### نوبت‌های کاربر

این مسیرها نیاز به توکن دارند:

```http
Authorization: Bearer <token>
```

```http
GET /api/appointments
POST /api/appointments
DELETE /api/appointments/:id
```

### مسیرهای ادمین

این مسیرها فقط برای کاربرانی قابل استفاده هستند که نقش `admin` دارند:

```http
GET /api/admin/appointments
PUT /api/admin/appointments/:id/confirm
PUT /api/admin/appointments/:id/cancel
```

## قوانین رزرو نوبت

- تاریخ باید با فرمت `YYYY-MM-DD` ارسال شود.
- ساعت باید با فرمت `HH:MM` ارسال شود.
- تاریخ باید امروز یا آینده باشد.
- ساعت رزرو باید بین `09:00` تا `17:00` باشد.
- اگر در همان تاریخ و ساعت یک نوبت غیرلغوشده وجود داشته باشد، رزرو جدید ثبت نمی‌شود.
- لغو نوبت باعث حذف رکورد نمی‌شود؛ فقط وضعیت آن به `canceled` تغییر می‌کند.

## خطاها

همه خطاهای API به صورت JSON برگردانده می‌شوند. نمونه:

```json
{
  "error": "Appointment time is already booked."
}
```

کدهای رایج:

- `400`: اطلاعات ورودی نامعتبر است.
- `401`: توکن وجود ندارد یا معتبر نیست.
- `403`: کاربر اجازه دسترسی ندارد.
- `404`: مورد درخواستی پیدا نشد.
- `409`: زمان نوبت قبلا رزرو شده است.
- `500`: خطای داخلی سرور.
